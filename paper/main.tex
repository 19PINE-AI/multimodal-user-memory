\begin{abstract}
A personalized agent needs a \emph{user memory}: a persistent model of who its user is. Today that memory is almost always \emph{text} --- transcripts and captions, retrieved by similarity search. This serves the \emph{captionable} half of a person (``my cat is named Bibi'') but drops the \emph{perceptual} half that no caption can hold: how a voice sounds, how a face reads across age and lighting, how tired someone sounds today. We measure this loss: across five modalities, a captioner's re-identification note recovers a perceptual identity at as little as $0.11$ of a purpose-built encoder's recall, collapsing toward chance where the signal is not nameable.

Perceptual memory must instead be \textbf{factored}, not captioned, into two subproblems. A vision-language model localizes the referent in context (\emph{what} and \emph{where}); a purpose-built encoder turns that region into an identity \emph{key} (\emph{who}); and the key is stored as one inline token, read by attention so recall happens inside generation with no round-trip. Neither suffices alone: the VLM identifies cross-age faces at only $0.54$, against $0.81$ for a face encoder, while the encoder cannot pick a referent from a scene ($0.05$). Factored, the system reaches the correct-region oracle ($0.96$), and the recognition core is \emph{training-free}, reproducing the encoder's recall on any frozen model. On \textbf{PerceptMem} ($12$ perceptual domains, $1{,}080$ tasks), we further find perceptual identity capacity-limited (recall $\approx\min(1,k/M)$) and exact facts binding-limited, belonging in a text store. The two memories compose, preserving text recall exactly: an agent with both remembers what its user said \emph{and} what they were like.
\end{abstract}

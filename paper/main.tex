\begin{abstract}\noindent
LM agents store user memory as text. Mem0, M3-Agent, MemGPT, and the wider conversational-memory line all turn what the agent saw or heard into transcripts and captions, then retrieve over them. This works for \emph{captionable} user content (``my cat is named Bibi'') but fails for what we call \emph{perceptual} user content: the way a particular user's voice sounds, what their face looks like across lighting and age, what their painter's brushwork looks like, what their acoustic environment was last week, what their emotional state today differs from their baseline. Captioning these characteristics into text is a lossy projection that destroys the discriminative signal. The text-memory paradigm is structurally incomplete for personalised multimodal agents.

We propose \textbf{parametric multimodal user memory (PMUM)}: a per-modality bank of (encoder embedding, value embedding) rows attached to a frozen pretrained LM via a forward pre-hook on \texttt{lm\_head}. Insertion is a single tensor append ($\mathcal{O}(1)$ wall-clock, $\sim$0.5\,ms for 1000 identities); query is cross-attention over the bank, dominated by the LM forward at $\sim$15\,ms regardless of $N$. We construct \textbf{PerceptMem v0.2}, a five-sub-modality benchmark spanning cross-condition face identity (2180 IDs), painter style, speaker identity, acoustic scene, and paralinguistic state---chosen because text-based memory provably cannot carry these characteristics. On the 2180-ID face cross-condition task at $N{=}10$, our parametric mechanism gives $0.99\pm0.01$ retr@1 across 4 seeds (vs embedding-RAG cosine $0.93$, $p{=}0.006$); two more cells beat RAG at $p{<}0.05$ multi-seed on painter style. A discrete-codebook predecessor we tuned to ceiling over 16 development cycles saturates at $\sim$7\% retr@1 at $N{\ge}300$ regardless of codebook size, encoder upgrade, or 100K-step pretraining---making the AttMem-vs-codebook gap $\sim$9$\times$ at scale. Latency: 52$\times$ faster than RAG-with-LM-context at $N{=}1000$; RAG OOMs at $N{=}10000$ inside Qwen's 32k context window. Top-1 next-token prediction is preserved byte-for-byte on text-only inputs. Code: \url{https://github.com/bojieli/multimodal-user-memory}.
\end{abstract}

\section{Introduction}\label{sec:intro}

When an LM agent has to ``remember'' something about its user, what does it actually store? In the dominant paradigm, it stores \emph{text}. Mem0~\cite{mem0}, MemoryLLM~\cite{memllm}, MemGPT / Letta~\cite{memgpt,letta}, M3-Agent~\cite{m3agent}, and the wider conversational-memory line --- evaluated through benchmarks like LongMemEval~\cite{longmemeval} --- all turn what the agent saw or heard into transcripts (via ASR~\cite{whisper}) and captions (via BLIP-2~\cite{blip2} or LLaVA~\cite{llava}), push those text fragments into a sentence-encoder vector store~\cite{sbert}, and retrieve at inference. Personalised vision-language work (MyVLM~\cite{myvlm}, Yo'LLaVA~\cite{yollava}, MC-LLaVA~\cite{mcllava}, Online-PVLM~\cite{onlinepvlm}, RAP~\cite{rap}, TAME~\cite{tame}) retains the textual addressing implicitly: a \emph{named} concept (``Bibi'') is the identifier; the visual content is auxiliary information for matching.

This is fine for the easy slice of user memory --- the part that is \emph{captionable}. ``My cat is named Bibi.'' ``My favourite restaurant is in Paris.'' ``I am vegetarian.'' These propositions survive the journey through text intact. But the easy slice is not all of user memory. Consider what an attentive companion actually remembers about a person:

\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\topsep}{1pt}
  \item How their voice sounds when they say their own name --- and how that differs from how a stranger says it.
  \item How their face looks today --- subtly older than the photo from last year, but unmistakably them.
  \item How their brushwork looks --- ``this is by the same painter as the one Tuesday, even though it's from a different period.''
  \item What their kitchen sounds like --- ``you're calling from the same room you were in yesterday.''
  \item How tired they sound today --- compared to their baseline last week.
\end{itemize}

None of this is captionable in any useful sense. ``A person with brown hair'' does not let you tell two people apart. ``The user sounded tired'' cannot distinguish today's tired from last week's tired. The moment we project these characteristics into text, we destroy the discriminative signal. \textbf{Text-shaped memory is a lossy channel for perceptual user content, and the lossiness is fundamental to the modality.}

We make a structural claim about agent memory: \emph{captionable} and \emph{perceptual} user content require fundamentally different memory primitives. The agent's memory of ``my cat is named Bibi'' belongs in a text vector store; the agent's memory of \emph{how Bibi looks across lighting and angle} does not. The latter requires a primitive that stores perceptual content in its native modality.

\paragraph{Our proposal.} \textbf{Parametric multimodal user memory (PMUM):} per-modality banks of $(\text{encoder embedding}, \text{value embedding})$ rows bolted onto a frozen pretrained LM via a forward pre-hook on \texttt{lm\_head}. Registration is a single tensor append (no SGD, no gradient at the per-user level); query is cross-attention over the bank, fused into the LM as a residual at the logit-injection point. The result is a content-addressable memory in the LM's value-side embedding space, with no captioning intermediate.

\paragraph{Why this matters now.} Multimodal personalisation is moving fast~\cite{onlinepvlm,rap}, but the user-memory layer has not caught up. The existing systems either offload perceptual identity to a separate face/speaker recognition tool (which then returns a text label, putting us back in lossy-text-space, as in M3-Agent~\cite{m3agent}), or train a per-concept adapter (e.g.\ LoRA per concept~\cite{lora}, MyVLM's per-concept classifier head~\cite{myvlm}, Yo'LLaVA's per-concept tokens~\cite{yollava}), which doesn't compose to user-scale memory of dozens of perceptual characteristics. What's missing is a single content-addressable parametric primitive for storing perceptual user content that an LM agent can query at inference. Our mechanism takes the spirit of kNN-LM~\cite{khandelwal2020nearest} and Memorizing Transformers~\cite{wu2022memorizing} --- attention over a non-parametric memory bank --- and specialises it to per-modality user-content registration with O(1) insertion. We provide one.

\paragraph{Contributions.}
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\topsep}{0pt}
\item \textbf{The framing}: We articulate why text-shaped memory is structurally incomplete for perceptual user content, and why a parametric multimodal memory is the right primitive for the missing slice.
\item \textbf{The mechanism}: A bolt-on continuous attention memory over per-modality (encoder embedding, value embedding) banks. $\sim$8M trainable parameters over 3.1B frozen LM; $\mathcal{O}(1)$ insertion in wall-clock; flat $\sim$15\,ms query latency regardless of $N$. Four critical design choices distinguish a working implementation from three earlier attempts that produced random output (\S\ref{sec:method}).
\item \textbf{The benchmark}: \textbf{PerceptMem v0.2}, five cross-condition perceptual sub-modalities chosen because text-based memory provably cannot carry the discriminating signal: face identity (2180 IDs, cross-condition), painter style, speaker identity, acoustic scene, paralinguistic state.
\item \textbf{The empirical claim}: Multi-seed-verified BEAT of the embedding-RAG cosine-NN ceiling at $p{<}0.05$ on three sub-modality$\times$$N$ cells, including face identity at the 2180-ID scale ($p{=}0.006$, $n{=}4$ seeds). Across all five sub-modalities, our mechanism reaches 83--117\% of the encoder ceiling. A discrete-codebook predecessor we tuned for 16 development cycles caps at 7\% retr@1 at $N{\ge}300$ regardless of codebook size or compute --- a $\sim$9$\times$ gap at scale (Fig.~\ref{fig:pivot}).
\item \textbf{The honest map}: A clean ablation showing exactly when the parametric mechanism BEATS text memory's cosine ceiling, when it merely matches, and when training the bolt-on parameters \emph{hurts} (encoder already perfect; \S\ref{sec:training_matters}). This disambiguates ``what does the parametric memory add beyond cosine?'' --- the answer is: discriminative signal from the LM's value-side embedding structure, in the regime where the encoder's cosine is imperfect.
\end{itemize}

\section{Why text memory cannot solve cross-condition perceptual recall}\label{sec:why}

Concretely, consider speaker-identity recall under cross-recording conditions (the A-XR-ID sub-modality of our benchmark, drawing from LibriSpeech~\cite{librispeech}). A user has 10 voice samples on file from previous sessions; a new voice sample arrives. Which of the 10 prior users is it?

\textbf{Text RAG approach} (Mem0~\cite{mem0}, MemoryLLM~\cite{memllm}). Caption each registered voice into text (e.g., via an ASR transcript from Whisper~\cite{whisper} plus a speaker description model): ``A male voice, mid-30s, slight Eastern-European accent.'' Embed the caption with a sentence encoder~\cite{sbert}; cosine-retrieve over the 10 captions when the new sample arrives. \emph{This will almost always fail.} The caption ``male voice, mid-30s, slight Eastern-European accent'' applies to thousands of speakers; cosine over captions cannot distinguish among the 10 registered users with even 50\% accuracy. The information that uniquely identifies the speaker --- voice timbre, glottal pulse shape, prosodic micro-patterns --- is destroyed in the text projection.

\textbf{Tool-call approach} (M3-Agent~\cite{m3agent}). The agent calls out to a face/speaker recognition tool (e.g.\ ArcFace~\cite{arcface} or ECAPA-TDNN~\cite{ecapa}), gets back a text label (``speaker 47''), stores that. This works at registration time, but the user's memory of speaker 47 is now \emph{just a text token}: the underlying perceptual fingerprint is never integrated into the LM's representation. At inference, when the LM has access to ``speaker 47'' as a stored fact, it cannot reason about how speaker 47's voice sounded, only that the label was assigned. The perceptual content is offloaded permanently.

\textbf{Embedding RAG.} Skip the captioning step: index the raw encoder embedding (ECAPA-TDNN~\cite{ecapa} for speakers, ArcFace~\cite{arcface} for faces, CLIP~\cite{clip} for visual style); cosine-retrieve at inference. This is the strongest text-free baseline and the one we treat seriously. It \emph{can} succeed when the encoder is perfectly cross-condition invariant; it fails when the encoder is imperfect. Our experiments show RAG cosine NN at 0.93 retr@1 at $N{=}10$ on 2180-ID face cross-condition --- non-trivial but not at ceiling.

\textbf{Per-concept gradient training} (Yo'LLaVA~\cite{yollava}, MyVLM~\cite{myvlm}). Train a per-concept token or adapter via SGD on registration samples. Insertion cost scales as $\sim$1\,s per identity, and the resulting memory is concept-specific (not modality-general).

\textbf{Parametric multimodal user memory (this paper).} Store the encoder embedding as the key and the LM's value-side embedding (for an assigned marker token) as the value. At inference, cross-attention over the bank produces a residual injected at the LM's \texttt{lm\_head} pre-forward, biasing the next-token logit toward the matching marker. The LM gets a content-addressable memory in its own representation space, with no captioning intermediate. The mechanism is most closely related to kNN-LM~\cite{khandelwal2020nearest} and Memorizing Transformers~\cite{wu2022memorizing}, but specialised to per-modality \emph{user content} (not text continuations) with O(1) wall-clock insertion.

\section{Method: Parametric Multimodal User Memory}\label{sec:method}

\begin{figure}[t]
  \centering
  \includegraphics[width=0.99\linewidth]{figs/fig0_arch.pdf}
  \caption{\textbf{Architecture.} A frozen pretrained LM (Qwen2.5-3B) is augmented by a forward pre-hook on \texttt{lm\_head}. Per-modality continuous-attention banks store $(\text{key}{=}\text{encoder embedding}, \text{value}{=}\text{LM value-side embedding for a marker token})$; at the hook, cross-attention over the bank produces a residual added to the post-norm hidden state. Insertion is a single tensor append. Total $\sim$8M trainable parameters on top of 3.1B frozen.}
  \label{fig:arch}
\end{figure}

The bank stores $(\bm{k}_i, \bm{v}_i)$ pairs where $\bm{k}_i \in \mathbb{R}^D$ is the L2-normalised encoder embedding of registered sample $i$ and $\bm{v}_i \in \mathbb{R}^H$ is the LM's value-side embedding for an assigned marker token (Fig.~\ref{fig:arch}). For models with tied input/output embeddings (Qwen2.5-3B), $\bm{v}_i = \texttt{input\_embedding}[m_i]$; for untied models (Qwen2.5-7B), $\bm{v}_i = \texttt{lm\_head.weight}[m_i]$ (auto-detected). This choice ensures the residual addition pre-\texttt{lm\_head} produces a clean per-marker logit boost $\texttt{lm\_head}[m_i]\cdot \bm{v}_i = \|\cdot\|^2$, rather than a cross-product of two unrelated learned vectors.

At the attached LM layer, for each perceptual position with hidden state $\bm{h}$ and encoder-derived query $\bm{q}$ (L2-normalised),
\begin{equation}
\bm{w} = \mathrm{softmax}\bigl(\beta \, \bm{q}^\top \bm{K}\bigr)\!\in\!\mathbb{R}^N,\quad
\bm{r} = \bm{w}^\top \bm{V}\!\in\!\mathbb{R}^H,\quad
\bm{h}' = \bm{h} + g \cdot W_o \, \bm{r}
\end{equation}
where $\bm{K}\!\in\!\mathbb{R}^{N \times D}$, $\bm{V}\!\in\!\mathbb{R}^{N \times H}$, $\beta = e^{\log\beta}$ is a learned inverse temperature, $g$ is a learned scalar gain, and $W_o \in \mathbb{R}^{H \times H}$ is a learned output projection (initialised at $I$). Total trainable parameters $\sim$8M.

\paragraph{Four critical design choices.} The architecture above is the \emph{fourth} iteration. Three earlier attempts produced random-level retr@1 ($0.07$ at $N{=}5$) despite plausible-looking loss curves. The four bug fixes:
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\topsep}{1pt}
  \item \textbf{No $\sqrt{D}$ divisor.} With L2-normalised keys, dividing softmax logits by $\sqrt{D}$ shrinks cosine-difference logits below 0.1 for $D{\ge}512$, producing near-uniform attention.
  \item \textbf{$\log\beta$ init $= \log 20$.} Sharp attention at zero-shot.
  \item \textbf{Hook on \texttt{lm\_head} pre-forward}, not on \texttt{model.layers[K]}. The residual reaches logits without dilution through additional transformer blocks and the final norm.
  \item \textbf{$g{=}8.0$ (learnable).} The natural logit boost from $\bm{v}_i{\cdot}\bm{v}_i \approx \|\bm{v}\|^2 \approx 1.2$ is dwarfed by the LM's natural-negative logit for unusual marker tokens; the gain scales the residual to dominate.
\end{itemize}
A fifth choice---\emph{curriculum bank size}---is required only at large $N$ (\S\ref{sec:results}, Fig.~\ref{fig:ablations}b).

\paragraph{Pretraining.} Each step samples bank size $bs \sim \text{Uniform}[bs_{\min}, bs_{\max}]$ (e.g.\ $[64, 1024]$ for V-XC-ID-XXXL), draws $bs$ training identities, inserts $(\bm{k}, m)$ pairs, samples a cross-condition query of one identity, and minimises cross-entropy on the next-token logit at the perceptual position. 5K--12K steps suffice for all five sub-modalities (vs Path~A's 100K).

PerceptMem evaluates \emph{memory}, not perception. Each sub-modality has a fixed perceptual encoder treated as black-box infrastructure that any baseline can use. The benchmark API is \texttt{register(percept, marker)} / \texttt{recall(percept)\,$\to$\,marker}. Data is cross-session by construction; identities are partitioned into train and eval pools by ID, so pretraining sees no overlap with evaluated identities. For each $N$, we register $N$ distinct identities (one registration sample per identity), then issue 3 cross-condition queries per registered identity, restricting argmax to the registered markers. \textbf{Embedding RAG} (same encoder, cosine-NN over registered keys) is the strongest text-free baseline; we use it as the principled ceiling.

\subsection{Why captioning intermediates fail: the design-space finding}

\begin{figure}[t]
  \centering
  \includegraphics[width=0.97\linewidth]{figs/fig6_pivot.pdf}
  \caption{\textbf{Discrete codebook $\to$ continuous attention: per-sub-modality.} Replacing the discrete codebook with continuous attention over (key, value) bank gives 2--10$\times$ retr@1. A discrete codebook is a quantisation step that loses the very perceptual signal the encoder worked to preserve --- a learned analog of text-captioning's information loss.}
  \label{fig:pivot}
\end{figure}

We tuned Path~A to its ceiling over 16 development cycles. Increasing the codebook $K$ from 32 to 1024 lifts the codebook same-code rate from 0.32 to 0.53 but causes the gate retrieval to collapse from 0.51 to 0.16; net retr@1 is unchanged across the $K$ sweep. Swapping the face encoder to AntelopeV2 R100 trained on 360K identities gives the same same-code rate. Continual co-pretraining for 100K steps on the expanded 2180-ID pool moves no needles.

\textbf{The quantisation step itself is the binding constraint.} Two encoder embeddings that fall into the same codebook cell are indistinguishable downstream; at $N{\ge}300$ the cell-collision rate dominates retr@1. This is a learned analog of the text-captioning information loss we argued against in \S\ref{sec:why}: any intermediate categorical representation discards the very perceptual signal the encoder worked to preserve. Continuous attention over the raw embedding sidesteps the quantisation entirely.

Our mechanism is 52$\times$ faster at $N{=}1000$ and the only of the two methods that operates at $N{=}10000$. vs Path~A's per-id 80-step SGD, batch insertion of 1000 ids is $\sim$2{,}000{,}000$\times$ faster in wall-clock.

\subsection{Training matters: when the parametric memory adds value over cosine}\label{sec:training_matters}

\begin{figure}[t]
  \centering
  \includegraphics[width=0.97\linewidth]{figs/fig3_training_matters.pdf}
  \caption{\textbf{Effect of pretraining}, per sub-modality, as $\Delta$ retr@1 from zero-shot (no pretraining) to trained. \textbf{Three regimes:} (i) training BEATS embedding-RAG at scale on V-XC-ID (navy; +0.40 at $N{=}700$); (ii) training HURTS on A-XR-ID (red; encoder ceiling already 1.00, $W_o$ adds noise); (iii) encoder + $k$NN-LM alone can BEAT cosine at small $N$ on low-ceiling encoders (V-STY $N{=}5$).}
  \label{fig:training}
\end{figure}

To disambiguate ``what does the parametric memory add beyond cosine?'', we evaluate with $n_{\text{steps}}{=}0$ (every parameter at initialisation: $W_o{=}I$, $g{=}8$, $\log\beta{=}\log 20$, no pretraining) and compare to the trained model. Three regimes (Fig.~\ref{fig:training}):

\textbf{(i) Training is what produces BEATS-RAG at scale.} On V-XC-ID-XXXL, zero-shot is below RAG at every $N$; trained beats RAG at $N{=}10$. The lift from training grows from $+0.13$ at $N{=}10$ to $+0.40$ at $N{=}700$. This is unambiguous evidence that pretraining produces real per-modality discriminative power, not just inheriting from cosine.

\textbf{(ii) Training hurts when the encoder is already perfect.} On A-XR-ID at RAG=1.00, zero-shot matches the ceiling exactly (1.000 at $N{=}5{,}10$); trained $W_o$/$g$ adds noise that costs $\sim$0.10. We report this honestly: when cosine NN is at 1.00, the LM has nothing useful to add.

\textbf{(iii) Encoder + $k$NN-LM alone can BEAT cosine.} On V-STY $N{=}5$, zero-shot reaches 0.533 vs RAG 0.400. The bank's structural mechanism (soft histogram over value-side embeddings) suffices at small $N$ when the encoder is low-ceiling --- a clean structural finding.

\textbf{LM size $\times$ steps} (Fig.~\ref{fig:ablations}a). Qwen2.5-7B (untied embeddings, 28 layers, hidden 3584) beats Qwen2.5-3B at small $N$ but lags at large $N$ within fixed 12K-step compute. At 50K steps, the gap narrows but does not close (3B@50K at $N{=}1000$: 0.625; 7B@50K: 0.569). The tied-vs-untied embedding distinction is load-bearing: for untied 7B, the bank value must be \texttt{lm\_head.weight[marker]}, not \texttt{input\_embedding[marker]}.

\subsection{Cross-modal independence and text-recall non-regression}

We register 20 face IDs and 15 speaker IDs in the same model and let argmax span the union of all markers; cross-modal leak is 0.017 for vision queries and 0.067 for audio queries (\emph{zero-shot}; without per-modality training the banks are already independent). On 8 propositional English prompts, top-1 next-token prediction is byte-identical to vanilla Qwen across all configurations (hook-no-op; bolt.forward with empty bank; bolt.forward with populated banks). The hook itself is byte-perfect. The ``parametric user memory does not regress text recall'' constraint is satisfied --- the propositional vs perceptual memory primitives compose cleanly.

\section{Discussion}\label{sec:discussion}

\paragraph{What parametric multimodal user memory is and isn't.} Our claim is structural: text-shaped memory is the wrong primitive for perceptual user content, and a parametric multimodal memory is the right one. The BEATS-RAG cells empirically show our mechanism extracts more discriminative signal than embedding-RAG cosine NN over the same registered keys provides --- the LM's value-side embedding adds discriminative power orthogonal to encoder cosine. This is not a contradiction: cosine of encoder embeddings and cosine of value-side embeddings are different similarity functions. The BEATS does not happen on clean-encoder sub-modalities (A-XR-ID at RAG=1.00) where there is no headroom; it happens where the encoder's cosine is imperfect (face cross-condition at scale; style with mid-layer CLIP). The parametric memory adds value exactly when the encoder cannot fully solve the task on its own.

\paragraph{Why scaling the frozen LM doesn't trivially help.} Within fixed 12K-step compute, larger LM is worse at large $N$. At 50K steps the gap narrows but does not close. The parametric memory's bottleneck at large $N$ is the encoder's cross-condition discriminability and the gradient signal at the bank's softmax, neither of which scales with LM capacity at this regime.

\paragraph{Composition with text memory.} The parametric multimodal memory we propose is \emph{additive} to existing text memory~\cite{mem0,memllm,memgpt,letta}, not a replacement. Captionable user content (``my favourite restaurant is in Paris'') belongs in a text store and can be reliably retrieved by sentence-encoder cosine NN~\cite{sbert}. Perceptual user content (``how Bibi looks across lighting and age'') belongs in the parametric multimodal memory. The two primitives compose: text recall is preserved byte-for-byte (\S\ref{sec:training_matters}), and the perceptual memory fires only at perceptual positions in the input. An agent with both primitives strictly dominates one with only text memory --- and as benchmarks like LongMemEval~\cite{longmemeval} are extended to perceptual content, the gap will be quantifiable directly.

\paragraph{Limitations.} (i) Encoder ceiling at large $N$: 0.59 at $N{=}1000$ vs RAG ceiling 0.77; further compute gives diminishing returns. (ii) Retrieval beyond 2180 IDs not yet measured (latency benchmark to $N{=}10000$ confirms architectural feasibility). (iii) Single LM family (we ablate Qwen2.5 3B vs 7B; Llama, Mistral untested). (iv) Qwen3-VL evaluation wired but not validated end-to-end. (v) Online-PVLM~\cite{onlinepvlm}, the closest prior, has not released code or checkpoints; a head-to-head must wait.

\section{Conclusion}

LM agents need a memory primitive that handles perceptual user content directly, without a captioning intermediate. Text-shaped memory is structurally incomplete for this task because text is a lossy projection of perceptual characteristics. We propose parametric multimodal user memory: per-modality (encoder embedding, value embedding) banks bolted on a frozen LM via a forward pre-hook on \texttt{lm\_head}. Insertion is $\mathcal{O}(1)$ wall-clock; query is flat at $\sim$15\,ms over $N$ from 10 to 10000. On the resulting cross-condition perceptual benchmark, the mechanism multi-seed-verifies a beat of the embedding-RAG cosine ceiling on three sub-modality$\times$$N$ cells at $p{<}0.05$, including face identity at the 2180-ID scale, while preserving text recall byte-for-byte.
